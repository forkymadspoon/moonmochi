    🛰️ Event triggers

    Fire an event.

    Each button sends exactly one event. Watch them land in your browser’s Network tab (filter for tr/?) or the console.

    PageView fires automatically on load. Every event is also mirrored to the DevTools console, and window.moonMochiPixelLab exposes sendStandard, sendCustom and state for firing events by hand.

    🔐 Customer data matching

    Off by default. Turn it on to attach hashed customer details to each event, so you can see how match quality is reported.

    ⚠️ Every value is invented test data on example.com. Never put a real person's details here — this is a public page. The tracking library normalises and SHA-256 hashes these values in your browser before sending, so they are passed as plain text; pre-hashing them yourself would double-hash and break matching. Toggling reloads the page, because this is applied at initialisation.
